Возможности Features

Один список вместо сотни инструкций. One list instead of a hundred guides.

Все твики сгруппированы по темам, снабжены понятными описаниями и ссылкой на конкретный ключ реестра или команду — чтобы было видно, что именно меняется. Tweaks are grouped by topic, with plain-language descriptions and a reference to the exact registry key or command — so you can see what actually changes.

ПриватностьPrivacy

Отключение телеметрии, идентификатора рекламы, журнала действий, распознавания речи и отправки диагностики. Disable telemetry, the advertising ID, activity history, speech recognition and diagnostic uploads.

Деблоат системыDe-bloat

Удаление предустановленных приложений, Xbox-компонентов, OneDrive и демонстрационных файлов — по выбору, а не оптом. Remove preinstalled apps, Xbox components, OneDrive and sample files — individually, not in one sweep.

Фоновые службыBackground services

Управление службами и задачами планировщика, которые расходуют память и диск при простое. Control services and scheduled tasks that eat memory and disk while idle.

Интерфейс проводникаExplorer UI

Показ расширений файлов, скрытых файлов, старого контекстного меню и отключение панели виджетов. Show file extensions, hidden files, restore the classic context menu and remove the widgets panel.

Откат измененийRollback

Перед применением создаётся снимок выбранных ключей. Любой твик можно вернуть, даже после перезагрузки. A snapshot of the selected keys is taken before applying. Any tweak can be reverted, even after a reboot.

ПортативностьPortable

Один исполняемый файл без установки, служб и драйверов. Настройки хранятся в профиле пользователя. A single executable with no installer, services or drivers. Settings live in your user profile.

Безопасность и предсказуемость Safety and predictability

Никаких «магических» оптимизаций. No magic optimizations.

NullTweaker не чистит реестр наугад, не трогает систему защиты и не отключает обновления безопасности. Каждый пункт описан словами и продублирован технической деталью. NullTweaker doesn't scrub the registry at random, doesn't touch the security subsystem and doesn't disable security updates. Every entry is described in plain words and backed by a technical detail.

  • Точка восстановленияRestore point Предлагается перед первым применением пакета изменений. Offered before the first batch of changes is applied.
  • Экспорт профиляProfile export Конфигурация сохраняется в .ntprofile — переносится между машинами. Configuration is saved to .ntprofile — portable between machines.
  • Открытый исходный кодOpen source Сборка воспроизводится локально, релизы подписаны и сопровождаются контрольной суммой. Builds reproduce locally; releases are signed and come with a checksum.
  • Без сетевой активностиNo network activity Приложение не отправляет данные наружу и не требует учётной записи. The app sends no data anywhere and requires no account.

Установка Install

Три шага и полторы минуты. Three steps, about ninety seconds.

01

Скачайте архивDownload the archive

Возьмите последний релиз со страницы GitHub. Проверьте SHA-256 — он опубликован рядом с файлом. Grab the latest release from the GitHub page. Verify the SHA-256 — it is published next to the file.

02

Запустите от администратораRun as administrator

Прав администратора требуют лишь ключи HKLM и удаление пакетов Appx. Распаковка не нужна — файл портативный. Administrator rights are needed only for HKLM keys and Appx removal. No unpacking — the file is portable.

03

Выберите профиль и применитеPick a profile and apply

Начните с пресета «Безопасный», проверьте список, снимите лишние галочки и нажмите «Применить». Перезагрузка — по желанию. Start with the "Safe" preset, review the list, uncheck anything you don't want and hit Apply. Reboot is optional.

FAQ

Частые вопросы Frequently asked questions

Это безопасно для системы? Is it safe for my system? +

Все изменения — задокументированные параметры реестра, службы и пакеты Appx. NullTweaker не удаляет системные файлы, не правит загрузчик и не отключает Защитник Windows. Перед применением создаётся снимок затронутых ключей. Every change is a documented registry value, service or Appx package. NullTweaker doesn't delete system files, doesn't touch the bootloader and doesn't disable Windows Defender. A snapshot of affected keys is taken before applying.

Можно ли всё вернуть назад? Can everything be reverted? +

Да. Кнопка «Откат» восстанавливает значения из последнего снимка, а точка восстановления системы покрывает случаи, которые твикер не отслеживает. Единственное исключение — удалённые приложения Appx: их придётся переустановить через Store. Yes. The Rollback button restores values from the latest snapshot, and a System Restore point covers anything the tweaker doesn't track. The one exception is removed Appx apps: those must be reinstalled from the Store.

Работает ли на Windows 10? Does it work on Windows 10? +

Поддерживаются Windows 10 1809 и новее, а также Windows 11 до 24H2 включительно. Твики, которых нет в текущей сборке, помечаются как недоступные, а не применяются вслепую. Supported on Windows 10 1809 and newer, and Windows 11 up to and including 24H2. Tweaks missing from your build are marked unavailable instead of being applied blindly.

Нужен ли интернет во время работы? Does it need the internet while running? +

Нет. Приложение не обращается к сети: нет проверки обновлений в фоне, нет телеметрии, нет лицензионного сервера. Скачивание новых версий — вручную. No. The app makes no network calls: no background update check, no telemetry, no license server. New versions are downloaded manually.

Стоит ли это что-то? Does it cost anything? +

Нет, проект бесплатный и с открытым исходным кодом. Здесь нет платной версии, подписки и встроенных покупок. No, the project is free and open source. There is no paid tier, no subscription and no in-app purchases.
